# Smart Hotel Review System

A Java-based Hotel Review & Recommendation System developed using Servlets, JSP, Maven, XML, HTML, CSS, and Bootstrap.

## Features
- User Registration & Login
- Add Hotel Reviews
- View Reviews Dashboard
- XML-based data storage
- Responsive UI using Bootstrap
- Java Servlet backend

## Technologies Used
- Java
- JSP & Servlets
- Maven
- XML
- HTML/CSS
- Bootstrap
- Apache Tomcat

## Project Structure
- src/main/java → Java Servlet files
- src/main/webapp → JSP pages and frontend
- WEB-INF → Configuration files
- pom.xml → Maven dependencies

## How to Run
1. Clone the repository
2. Import as Maven Project
3. Configure Apache Tomcat
4. Run on server
5. Open:
   http://localhost:8080/HotelReviewSystem/
